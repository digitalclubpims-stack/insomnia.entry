# INSOMNIA Entry Portal — UI revision

This revision addresses the mobile screenshots:
- Replaced the heavy stencil display font with Space Grotesk + DM Sans.
- One shared panel/card system across home, ticket, CR, scanner and admin pages.
- Removed nested oversized cards on the ticket page.
- Responsive forms use one column on portrait phones and two columns only where there is room.
- Navigation wraps/scrolls instead of disappearing into an inconsistent layout.
- Scanner controls, camera stage and confirmation action are responsive.
- Ticket is a compact phone-first pass with a consistent visual hierarchy.
- Print styling produces a clean ticket.
